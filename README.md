# ScanPDF · 扫描王替代扫描转PDF

支持自动裁边、透视矫正，以及**浅色纸纹／背面透印淡化**。

**演示站：[https://pdf.090803.xyz/](https://pdf.090803.xyz/)**

建议使用手机自带浏览器打开（iPhone 使用 Safari），方便通过系统分享菜单将 PDF 发送到微信。iPhone Safari 已实测可以分享；不建议在微信内置浏览器中使用文件分享。

独立编写的静态网页，没有复用 Nitidoc 源码。将 `dist/` 部署到 HTTPS 静态站点即可使用。相机需要 HTTPS 或 localhost；手机访问电脑局域网 HTTP 地址通常不能使用实时相机。

支持实时相机、系统拍照入口、相册多选、纸张四角自动检测、手动调角、透视矫正、A4 横竖比例、扫描滤镜、排序、旋转、多页 PDF、Web Share 文件分享及下载兜底。

照片只保存在当前标签页内存，不上传、不持久化。刷新或关闭页面会丢失本次扫描。最多 40 页；低内存手机建议分批处理。白纸配白桌面、阴影和遮挡会影响自动识别。去阴影增强先估算局部纸张底色，再校正亮度和偏色、轻度锐化；黑白净纸在校正后分离文字与背景。彩色照片或深色纸张建议使用原图色彩。手机默认系统高清拍照，实时取景为备选。图像长边上限 3200 像素。

微信内置浏览器、iOS Safari、Android 浏览器的相机、下载、文件分享表现不同，需要真机验证；系统分享不保证提供微信目标。下载后可通过系统文件管理器发送到微信。

`verify.cjs` 使用本机运行时 canvas 和随附 OpenCV 检查模拟斜纸四角、A4 矫正和两页 PDF；测试产物位于 `qa/`，不部署。模拟测试不能替代手机真机验证。

第三方组件：jsPDF 2.5.2（MIT）；OpenCV.js 4.10.0，由 @techstark/opencv-js 分发（OpenCV Apache-2.0）。许可证见 `dist/vendor/`。

每页新增“优化”：实时低分辨率预览、保存时全尺寸处理；文字加黑、白底提亮、去黄、淡化纸纹/背面透印；一键净纸、原始裁剪对照和还原。参数随页面保存；原始照片不覆盖。新增调节排除饱和彩色标记，但净纸/灰度模式仍可能影响浅色字迹和彩色内容，请对照检查。这些是本地图像算法，不是 AI 模型。

## 运行与测试

部署：将 dist/ 上传至任意 HTTPS 静态主机。Cloudflare Pages 项目名称 pdf，生产域名 https://pdf.090803.xyz/ 。

测试：Node.js 22+，先运行 `npm install`，然后 `npm test`。测试样张和 PDF 写入 qa/，无需上传到服务器。
